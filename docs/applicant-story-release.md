## AI coach and resume

Five experience topics cover projects, competitions, research, community/responsibility and goals. The coach asks one follow-up grounded in notes, accepts having no experience and helps describe completed activities. Resume bullets require exact source quotes from applicant notes; the applicant can edit/remove them and must explicitly approve saving. This verifies quote provenance, not full semantic correctness. The result is a starter resume, not automatic application submission or a guaranteed admissions strategy.

Server requests include only interests and experience notes; account identity, email and academic scores are excluded from the coach payload. The provider key stays server-side. Failed/cancelled requests preserve the draft. Account data persists through the existing profile store; browser drafts are account-scoped. Saved resume content can be downloaded as text or printed/saved as PDF through the browser.

Model: existing provider-listed `google/gemini-3.7-flash`. Live English and Kazakh resume samples returned in 7.561 and 8.238 seconds and preserved literal evidence quotes from Russian notes. One Russian interview request failed; a later live attempt succeeded. This is a small reliability sample, not an SLA; model outputs require review.
