# PathShift — версия для презентации

> После этой фиксации пользователь запросил упрощение и пересмотр продуктовой идеи. Актуальное решение описано в [product-focus.md](product-focus.md). Предыдущий тег сохранён как воспроизводимая версия.

## Зафиксированный объём

Рабочий сайт: https://pathshift-locus-2026.vercel.app/

Продукт для международного поступления на Computer Science, Fall 2027, с 12 программами и преимущественно IB-профилем. Основной путь: анкета → диагностика → варианты → сравнение → сценарий → план → прогресс. Русский, казахский и английский интерфейсы.

## Закрыто в финальном проходе

- Личный план учёбы и активностей: до 40 задач, категория, целевая дата, заметки/результаты, редактирование, выполнение, подтверждение удаления и текстовый экспорт. Задачи сохраняются в профиле и входят в резервную копию. Выполнение не меняет академические требования или готовность к поступлению.
- Импорт JSON-копии: проверка размера, версии, структуры и значений; предварительный просмотр; явное подтверждение замены; прежний профиль остаётся в локальной резервной копии. Файл с ошибкой не заменяет текущие данные.
- Проверка согласованности IELTS overall с четырьмя известными компонентами по официальному правилу округления. Неизвестные компоненты не дополняются вымышленными значениями.
- Проверка совпадения исходной оценки и IB total, когда явно указана шкала 45; проверка числа HL-курсов уже была добавлена ранее.
- В сценарии показано число готовых маршрутов «сейчас → сценарий». В карточках отдельно видны невыполненные условия профиля и правила вуза, требующие уточнения.
- Поля бюджета принимают произвольную целую сумму, а не только шаг 1000.
- Новые функции локализованы; проверены мобильное размещение и автоматическая доступность.

## Осознанные границы релиза

Это зафиксированный хакатонный продукт в указанной области данных. UNKNOWN по университетским правилам и будущей полной стоимости остаётся UNKNOWN. Нет обещаний поступления, гарантированных грантов, автоматической подачи заявлений или автоматической рассылки. Нет аккаунтов и облачной синхронизации; перенос профиля выполняется через экспорт/импорт. Учебные задачи — личный план, а не сертифицированная программа подготовки. Полноценная поддержка других направлений, национальных учебных систем и TOEFL/DET требует новых проверенных источников и относится к будущему развитию.

## Правило фиксации

До презентации не расширять каталог, не менять дизайн и правила оценки без воспроизводимой блокирующей ошибки. Для демонстрации использовать сценарий из README и синтетический профиль Aruzhan. Не вносить реальные персональные данные участников в демонстрацию. Конкурсные видео, слайды, реальные роли команды и доступ жюри — следующий отдельный этап.

Результаты локальных и опубликованных проверок записаны в [validation.md](validation.md).
