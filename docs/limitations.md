# Current limits

- Scope: international first-year CS, Fall 2027, 12 programs; academic normalization primarily covers the supplied IB predicates. Other curricula retain original grades and unknown mappings.
- Complete academic/application predicates remain incomplete for CMU, Purdue, RIT, ASU and Manchester. UBC, UIUC and Toronto retain mapping gaps. IELTS improvement alone cannot establish full readiness there.
- Numeric English evaluation currently supports IELTS. Other tests/exemptions may exist and need verification. SAT/ACT presence is evaluated where required, without a fabricated competitive cutoff.
- All 2027 annual totals remain unknown. Four cost references retain 2026–27; UW/Waterloo subtotals cannot prove full affordability. No FX conversion or guaranteed aid.
- Unknown timezone precision stays unknown at boundaries. Recourse uses the entered completion date; it does not guarantee preparation, a score or delivery. It is a bounded search over supported mutations, not a global optimizer over all policies.
- Document readiness is an institution-specific user declaration, not automatic document verification. AIF is separate. Institution portals remain authoritative. No automatic applications or messages are sent.
- A conditional English route is not an offer. Waterloo's common gates apply; 2026 BASE dates are not reused for 2027. RIT retains its academic gap. Post-enrolment specialization is distinguished from first-year admission.
- Next action uses a visible product policy: prerequisites satisfied, earliest known deadline, dependency count, most shortlisted programs affected, stable ID. Interest changes add labeled planning suggestions, not invented course offerings or admissions advantages.
- Persistence is local to this browser/device; no accounts, cross-device sync or server database. Application code does not log profile payloads.
- Automated accessibility checks do not replace a complete assistive-technology audit. The main journey, keyboard dialog dismissal, mobile layout and persistence are tested.

- Version 1 JSON profile backups can be imported after validation and preview; a local copy of the replaced profile is retained. There is no automatic cloud sync.
- The personal study/activity planner stores up to 40 tasks with dates, notes and completion. It is user-directed preparation, not proof of admission eligibility. It does not send scheduled notifications.
