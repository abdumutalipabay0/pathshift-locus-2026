Главный пример комплекта: синтетический профиль Аружан → интерес и опыт → UW–Madison → IELTS 6.0 против порога 6.5 → отдельный сценарий 6.5 → проверка документов как следующий шаг. Сценарий 6.5 выполняет только языковую проверку; это не гарантия поступления и не изменение фактического результата.

Сценарий и тайминг — в [питч-скрипте](../pitch-script.md). Слайды на русском; снимки экрана сделаны с текущего опубликованного [демо PathShift](https://pathshift-locus-2026.vercel.app/) в английском интерфейсе, чтобы все кадры были в одном языке. Это **вымышленный профиль Аружан**, а не реальный абитуриент. Снимки нельзя выдавать за результаты пользовательского исследования или гарантии поступления.

Для восьми слайдов достаточно двух-трёх крупных скриншотов. Остальные — для живого демо и запасного кадра. Не пытайтесь уместить на одном слайде целый интерфейс: обрежьте кадр вокруг одной понятной мысли, сохранив контекст и подпись «Демонстрационный профиль». Не смешивайте слайд 8 с историей UW–Madison без объяснения: исходный демопрофиль включает UBC, поэтому его следующий шаг относится к UBC.
