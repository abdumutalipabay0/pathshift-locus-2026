Для восьми слайдов достаточно двух-трёх крупных скриншотов. Остальные — для живого демо и запасного кадра. Не пытайтесь уместить на одном слайде целый интерфейс: обрежьте кадр вокруг одной понятной мысли, сохранив контекст и подпись «Демонстрационный профиль». Не смешивайте слайд 8 с историей UW–Madison без объяснения: исходный демопрофиль включает UBC, поэтому его следующий шаг относится к UBC.
